
# Student Performance Analytics System

## 1. Project Overview
The Student Performance Analytics System is a Python-based project that analyzes student academic performance using Pandas and NumPy.

## 2. Objectives
- Store student information in a CSV dataset.
- Calculate total and average marks.
- Assign grades to students.
- Identify Pass and Fail students.
- Find the class topper.
- Display dataset statistics.
- Generate a student analysis report.

## 3. Technologies Used
- Python
- Pandas
- NumPy
- CSV Dataset
- Visual Studio Code

## 4. Dataset Description
The dataset contains 20 student records.

Columns include:
- Student_ID
- Name
- Department
- Python
- Math
- English
- Attendance

## 5. Project Files
- `main.py` — Main program that runs the analysis.
- `functions.py` — Functions for average calculation, result assignment, and topper detection.
- `students.csv` — Student dataset.
- `student_analysis_report.csv` — Generated analysis report.
- `Project_Documentation` — Project documentation.

## 6. Key Features
- Reads student data using Pandas.
- Calculates total and average marks.
- Assigns grades and Pass/Fail results.
- Displays dataset statistics.
- Identifies the class topper.
- Displays Pass/Fail summary.
- Saves the analysis report as a CSV file.

## 7. How to Run
1. Install Python.
2. Install the required libraries:

   `py -m pip install pandas numpy`

3. Open the project folder in VS Code.
4. Run the program:

   `py main.py`

## 8. Output
The program displays student records, total students, subject statistics, the class topper, and Pass/Fail summary. It also generates `student_analysis_report.csv`.

## 9. Final Outcome
The project demonstrates how Python, Pandas, and NumPy can be used to process and analyze student performance data.
